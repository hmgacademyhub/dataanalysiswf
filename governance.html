Privacy posture

  • No data ever leaves your browser unless you export it.
  • Persistence is in IndexedDB (origin-isolated).
  • No third-party tracker, analytics or AI API is loaded.
  • Audit events are chained with SHA-256 so tampering is detectable.
How the hash chain works

Every audit event stores hash = SHA-256(ts | action | details | prevHash). To insert, delete or modify any historic entry, an attacker would have to rebuild every subsequent hash — which the verify button instantly detects.
