Master the Data Analysis Workflow

A professional, cumulative curriculum designed to take you from raw datasets to executive insights.

1

Foundation: Ingestion & Tidy Data

Beginner

Analysis starts with data structure. Learn to load CSVs, Excels, and Google Sheets while maintaining a 'Tidy' format where each row is an observation and each column is a variable.

  • Data Types & Schema Detection
  • Primary Keys & Uniqueness
  • Public API Synchronization

Action Task

Upload a sample dataset and check the total rows and column count in the Ingest hub.

Go to Ingest Hub
2

Processing: Data Quality & Cleaning

Intermediate

Dirty data leads to wrong decisions. Master the art of profiling (diagnosing) and cleaning (rectifying) your dataset to ensure 100% reliability.

  • Null Rate & Imputation Strategies
  • Statistical Outlier Treatment (IQR)
  • Deduplication & Case Standardization

Action Task

Find the column with the highest null percentage and apply a constant fill value.

Go to Cleaning Hub
3

Transformation: Structural ETL

Intermediate+

Once clean, data must be reshaped for analysis. This mimics Power Query in Excel or dbt in SQL, creating new metrics and joining disparate tables.

  • Calculated Columns (Logic-based)
  • Inner and Left Join Operations
  • Unpivoting Wide Data to Long Format

Action Task

Create a 'Total Revenue' column by multiplying [Quantity] and [Price].

Go to ETL Hub
4

Intelligence: BI & Modelling

Professional

The final frontier: turning data into stories. Using interactive dashboards and data science models to find the 'Why' behind the numbers.

  • Interactive Slicers & Cross-Filtering
  • RFM Segmentation (Recency, Frequency, Monetary)
  • Pareto Analysis (The 80/20 Rule)

Action Task

Run a Pareto analysis to find the 20% of products driving 80% of revenue.

Go to BI Hub
5

Governance: Ethics & Compliance

Enterprise

Professionalism requires accountability. Learn to document your work with audit trails and handle sensitive data using privacy-first architectures.

  • Chronological Audit Logging
  • Access Control Matrices (ACM)
  • Zero-API Privacy Frameworks

Action Task

Visit the Governance Hub and review the a Zero-API Notice to ensure data security.
