# Competitive Research Summary

Observed feature patterns from Tableau, Power BI, Alteryx, OpenRefine, Rows/AutoEDA-style tools and analytics sandboxes:

- Robust connectors and flat-file ingestion.
- Self-service dashboards and visual exploration.
- Data cleaning workflows that are reproducible and exportable.
- Data dictionaries, lineage and governance metadata.
- Quality scoring, anomaly checks and audit trails.
- Command/search interfaces for discoverability.
- Reusable semantic/recipe layers.
- No-code/low-code transformations plus optional SQL.
- Offline/local workflows for privacy and cost control.

Enhancements implemented in this package focus on free, client-side versions of those patterns: offline CSV fallback, command search, feature guide, workspace health audit, data dictionary, lineage, recipes, simple SQL fallback, SEO files and deployment docs.
