Formula syntax

Wrap column names in square brackets: [Price] * [Qty], [Revenue] - [Cost], Math.log([Sales]+1), String([Name]).toUpperCase().

A formula compiles to function(row){ return ...; } inside a sandbox that blocks window, fetch, eval and Function, so it cannot exfiltrate data.
