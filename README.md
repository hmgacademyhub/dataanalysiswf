# DAWF v2 Enhanced — Official Release

DAWF (Data Analysis Workflow) v2 Enhanced is a professional-grade, serverless BI platform built for secure enterprise-level data exploration.

## 🚀 Key Improvements in v2
- **AlaSQL Integrated:** A full SQL engine running in your browser.
- **Executive Reporter:** Narrative-based reporting with Markdown and dynamic data.
- **Data Lineage:** Automated tracking of data transformations.
- **Calculated Fields:** Custom JS-based formula constructor.
- **Improved Join Engine:** Multi-file relational blending (Left/Inner joins).
- **Secure Auth Fixed:** Full access control with `HMG2025` passcode.

## 🛠 Deployment Instructions (Detailed)

### Option A: Local Usage (No Server Needed)
1.  Download and unzip `dawf_v2_enhanced.zip`.
2.  Open the `dawf v2` folder.
3.  Double-click `index.html`.
4.  Enter credentials:
    *   **User:** `admin`
    *   **Passcode:** `HMG2025`

### Option B: GitHub Pages (Free Hosting)
1.  Log in to your GitHub account.
2.  Create a new repository (e.g., `my-bi-platform`).
3.  Upload **all files** from the `dawf v2` folder to the repository.
4.  Navigate to **Settings > Pages**.
5.  Under **Build and deployment**, select `Deploy from a branch` and choose `main`.
6.  Your platform will be live at `https://[your-username].github.io/[repo-name]/`.

### Option C: Professional Hosting (Vercel/Netlify)
1.  Connect your GitHub repository to Vercel or Netlify.
2.  The platform is static—no build command is required.
3.  Set the root directory to `dawf v2` if you didn't upload it to the repository root.
4.  Deploy.
